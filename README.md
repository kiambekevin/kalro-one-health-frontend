# 🌾🐄 KALRO One Health Digital Platform (Frontend)

An integrated, web-based platform developed for the **Kenya Agricultural and Livestock Research Organization (KALRO)**. This platform operationalizes the **One Health** framework—unifying human, livestock/animal, plant/crop, and ecosystem health data to support disease surveillance, agricultural decision-making, and climate resilience in Kenya.

---

## 📌 Overview

The **KALRO One Health Frontend** provides an intuitive user interface for farmers, agricultural extension officers, researchers, and public health officials. By expanding beyond traditional crop-only platforms, this application delivers an integrated dashboard for monitoring crop diseases, livestock health, zoonotic risks, and environmental indicators in real time.

---

## ✨ Key Features

- **🌐 Integrated One Health Dashboard:** Unified monitoring for crop health, livestock wellness, and environmental alerts.
- **🌱 Crop Health Diagnostics:** Real-time diagnostics, advisory services, and pest/disease tracking.
- **🐄 Livestock & Veterinary Care:** Surveillance and reporting tools for animal health and zoonotic risk management.
- **📍 Interactive Geospatial Mapping:** Regional disease outbreaks and agricultural data visualization across Kenyan counties.
- **📱 Responsive & Mobile-First Design:** Accessible across desktop computers, tablets, and low-bandwidth mobile devices.
- **🌍 Multilingual Interface:** Swahili and English support for localized accessibility.
